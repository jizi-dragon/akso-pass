账号存在云端

只有云端一种数据源：账号存在服务器上的账号库里，换一台电脑登录就能用。 本机不再保存账号库，也不再有"本地 / 云端"的切换。

离线时：本机会保留一份**只读副本**，用于断网时查看与打开页签。 副本不含平台口令，所以离线时不能新增 / 编辑，自动填表也不生效。 恢复到在线后会自动切回实时数据。

口令：由服务端加密存放，本机不落明文。

并行账号

每账号独占自己的标签页与存储命名空间，互不登出。按盒子收纳，悬停卡片可批量勾选。

    添加并行账号

    页签名即该账号所有标签页的标题；密码 AES-GCM 加密存放在本机。

    每行一条：页签名,账号名,密码（也支持 JSON 数组）。导入到上方所选站点与盒子。

    站点管理

    站点存在云端账号库里，这里只做增删改。删除一个站点会把它下面的账号一并删除（会先让你确认）。

    站点名称只影响显示；账号绑定的是站点地址。留空时自动用地址当名称。

      盒子管理

      盒子用来把账号分组，轮盘按盒子翻页。每个盒子可以关联一个站点； 默认盒子是兜底盒 —— 它不能改名、不能删除、不能禁用，也不参与站点关联。

      盒子的名字、禁用态与站点关联都以云端为准，会自动同步；改动会在下一次刷新时生效。

        常用页面
