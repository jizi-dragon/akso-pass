自动截图

在「站点管理」里配置过的站点中，从工具栏点「录制整个浏览器」开录：每次点击 / 输入自动截一张带描边的图， 最后导出成可读的操作手册（Word / Markdown）。

录制

● REC

开始：点浏览器工具栏上的 Akso Pass 图标 →「录制整个浏览器」。 录制范围是整个浏览器：新开的页签、弹出式新窗口、切换到的旧页签都会自动接上； 做完操作回到这一页点「停止录制」。

还没有「在所有网站上读取数据」权限：新页签里的步骤只会记文字、没有截图。

截图要「在所有网站上读取数据」这一条权限（Chrome 只认它；站点级授权和全网通配都不够）， 它只在录制时用来取当前前台页签的画面。Chrome 不允许扩展自己交还这项权限， 要收回请到 chrome://extensions 的「详细信息」里改。
