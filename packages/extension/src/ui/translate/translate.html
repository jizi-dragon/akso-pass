翻译面板

光标放进输入框 → Ctrl+X → 译文进剪贴板

翻译功能已关闭：页面上不会出现翻译图标，Ctrl+X 也不会响应。打开右上角开关即可恢复。

怎么用

两条路径并存，语义不同 —— 别再猜哪个是哪个。

Ctrl+X
取译文到剪贴板 光标在输入框内时按一下。翻译并复制，原输入一字不动，到下一个框直接 Ctrl+V。
🔵
点图标回填原文 翻译并覆盖原框（会改掉你写的中文）。

快捷键改键去 chrome://extensions/shortcuts —— 当前生效键位：Ctrl+X。 若显示「未设置」，说明被别的扩展占用了，请到该页面重新指定。

译文长度限制

默认限制译文最多 50 个字符；关闭后引擎返回多长就保留多长。

只限制译文，不限制输入框原文；命名规范模式先转换再按 50 字符截断。 需要完整长句时把此开关关掉。

命名规范模式

翻译结果转成 snake_case，可直接当字段名 / API 参数名 / 变量名。

结果 —

含换行的段落原样保留（多行是段落不是字段名）；单行不论多长都转换； 超 60 字符按完整单词截断；结果短于 3 字符则保留原文。

高级设置 英语 · 自动模式 ▾

目标语言

源语言固定为自动检测。 有道只服务中↔英方向且不接受语言参数，选其它语言时它会失败并由兜底引擎接管。

翻译引擎

全部引擎免费、无需 API Key、无需注册。自动模式并行赛马两个国内引擎，谁快用谁； 都失败再依次用海外两路兜底 —— 要 4 路同时挂才会失败。 返回词典释义（含「/」或 sth/sb）的引擎会被自动跳过，不会把词条当译文给你。

翻译内容会发送到第三方。 请求由浏览器直接发往腾讯交互翻译 / 网易有道 / MyMemory / Lingva 的公开接口， 不经过本项目任何服务器。含敏感信息的字段请不要翻译。
